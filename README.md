# Give Me Some Good News

**A catalog, coverage map, and combined feed of the local newsrooms being
built to last** — nonprofits, worker-owned cooperatives, family and
community papers, Native and Black-owned and Spanish-language outlets, and
the small university and nonprofit magazines that make up an arts desk.
Chains and hedge-fund papers are out of scope, and so are the metro
dailies; the point is local newsrooms. They're surviving; this site is for
reading them.

Live at **<https://givemesomegood.news>**.

The output is plain HTML with one small inline stylesheet. The only
JavaScript is two small enhancements — infinite scroll on the feed, and
tap-a-dateline-for-your-own-timezone — and the site works fully without
either. IBM Plex is served from here rather than a font CDN, for the same
reason images are cached locally: no third party needs to see who is
reading. Everything links back to the newsrooms.

## What's here

```
data/orgs.yaml          the hand-curated catalog (slug, url, place, model,
                        features, feed hints). Add a newsroom here.
data/orgs_literary.yaml the arts desk: literary, ideas and arts magazines
data/orgs_directory.yaml  bulk import, generated — never hand-edit
data/sources/           the directories the import came from, as fetched
data/us_places.tsv      Census gazetteer, for offline geocoding
data/institutions.yaml  funders, networks and associations
data/about_overrides/   hand-collected About text for sites whose firewalls
                        block scripted fetches (with source URLs)
data/catalog.json       machine-readable export, regenerated by the build
data/us_states.geojson  state outlines for the map (US Census-derived)
assets/fonts/           IBM Plex woff2, copied into site/fonts/ at build
schema.sql              Postgres schema; requires pgvector
givemesomegoodnews/     the pipeline (Python, five small dependencies)
site/                   the generated site (committed so it can be served
                        as-is; site/img/ is a local image cache and is
                        gitignored, rebuilt by the crawl)
```

## How it works

1. **`seed`** upserts all three catalog files into Postgres; the
   hand-curated `orgs.yaml` always wins on slug.
2. **`fetch_about`** pulls each org's About page and stores its main text —
   the catalog describes every newsroom *in its own words*, quoted and
   attributed, never paraphrased. Overrides in `data/about_overrides/`
   win over live fetches (for WAF-blocked sites).
3. **`fetch_support`** crawls each org's homepage for the page where a
   reader can pay them — a Donate page, a membership page, a
   subscription. Every feed item links to it. Links are scored (payment
   processors rank high, newsletter signups are excluded); a hand-set
   `support_url` in `orgs.yaml` always wins.
4. **`fetch_feeds`** finds each org's RSS/Atom feed (configured hint →
   `<link rel="alternate">` autodiscovery → common paths, including the
   Arc and TownNews patterns), then stores new articles with their
   headline, summary, author, the publisher's own categories, and an
   image. Syndicated wire copy (`/wires/` URLs) is skipped. Every article
   gets an embedding at insert time.
5. **`classify`** fills in subjects the publisher didn't declare (below).
6. **`build_site`** renders plain HTML from the database: the catalog
   grouped by state, an Albers-projected SVG coverage map, the combined
   feed newest-first, one page per subject, per-org pages, a
   self-contained `onepage.html`, and the cross-region **connections**
   page.

### Where the catalog comes from

`orgs.yaml` is hand-curated. `orgs_directory.yaml` is generated by
`import_directory` from the [Media and Democracy
Project](https://www.mediaanddemocracyproject.org/journalism-directory)
directory, kept in `data/sources/`. The importer drops chain-owned papers,
drops national wire services (The Center Square, Public News Service) that
the directory files as nonprofits, drops rows whose only website is a
Facebook page, and keeps one entry per site. Re-running it never touches
hand-written entries.

Coordinates come from the Census gazetteer via `geocode.py` — offline, no
API key, deterministic. Directory city fields are free text, so most
resolve to a place, some only to a county, and the rest to a state
centroid; `orgs.geo_precision` records which.

### Tags

Each newsroom carries tags for what it is rather than a paragraph about
itself: **Nonprofit**, **Co-op**, **Worker-owned**, **Family-owned**,
**Journalist-owned**, **University-affiliated**, **Public media**,
**Independent**, and community tags like **Black-owned**, **Spanish**,
**Native-owned**, **LGBTQ+**, **Street paper**, **INN member**. Ownership
tags are matched from each newsroom's free-text `model`; community tags
come from the directory. Every tag gets its own page.

### The archive

Stories are never deleted. A piece that has aged out of its publisher's own
feed may not be easy to find anywhere else, so `prune` only garbage-collects
cached image files that no article points at any more.

At the observed rate — around 1,500 stories a day across roughly a thousand
live feeds, about two thirds carrying a picture — the database grows about
3GB a year and the image cache about 11GB. On a 50GB disk that is a few
years of headroom. If it ever gets tight, `prune --images-older-than N`
releases the local *copy* of old pictures while keeping the story, its link,
its text and its `image_url`; a block-storage volume is the other answer.

### Images

Feed images are downloaded, downscaled to 480px wide, and served from this
site (`site/img/`, named by SHA-1 of the source URL). Nothing is hotlinked:
a publisher's server is hit once per image rather than once per reader, and
the page keeps working when they reshuffle their CDN. `image_url` keeps the
provenance. A broken image is a missing image, never a failed crawl.

### Subjects

Every article is tagged with one of eleven subjects — News, Politics,
Education, Health, Environment, Housing, Business, Arts, Sports, Food,
Opinion — in three layers, most trustworthy first. No language model is
involved.

1. **declared** — the publisher's own RSS categories, mapped through a
   whitelist in `givemesomegoodnews/subjects.py`. About four in five entries
   carry categories. The whitelist is what separates real subjects
   (`education`, `sports`) from place names (`jefferson county`) and CMS
   furniture (`home: lead`, `uncategorized`): an unmapped term contributes
   nothing rather than guessing.
2. **url** — whole path segments like `/sports/` or `/opinion/`, for the
   newsrooms whose feeds declare nothing.
3. **vector** — `classify` averages the embeddings of everything labeled by
   layers 1 and 2 into one centroid per subject, then gives each remaining
   article its nearest centroid, if it is both close enough and clearly
   closer than the runner-up. Ambiguous stories stay untagged.

Layer 3 works with the hashing embedder because a centroid of hundreds of
sports stories is dense in the vocabulary sports stories actually use.
Matching against the bare *word* "Sports" would not work at all — it is one
hashed bucket that most sports articles never contain. Thresholds are
`MIN_SUBJECT_SIM`, `MIN_SUBJECT_MARGIN`, and `MIN_SUBJECT_SEEDS`.

### Search

`/search` is the one page that isn't a static file: it runs
`givemesomegoodnews.searchd`, a small local HTTP service behind nginx that
queries Postgres full-text search (`websearch_to_tsquery`, so quotes, `OR`
and `-word` all work). Titles are weighted above summaries. It is a plain
GET form, so it works without JavaScript, and the rest of the site keeps
serving if the service is down.

Not a client-side index on purpose: shipping every headline and summary to
every reader would cost more bandwidth than the whole feed does.

### The vector part

Articles live in an `articles` table with an `embedding vector(384)`
column and an HNSW cosine index (pgvector). That powers:

- **Connections across regions** — for recent articles, the nearest
  neighbor from a *different state*; the strongest pairs become
  `connections.html`. This is where you see five Western outlets carrying
  the same wildfire investigation, or Mississippi Today and Verite News
  circling the same police story from two states.
- **Related links in the feed** — cross-state echoes under feed items.
- **Search** — `python3 -m givemesomegoodnews.search "housing eviction" -k 10`.

The default embedder (`givemesomegoodnews/embedder.py`) is deterministic local
feature hashing: unigrams+bigrams hashed into 384 signed buckets, L2
normalized. No model downloads, no API keys, and good enough to catch
shared-vocabulary stories. It is built to be swapped: any embedder with
`.dim`, `.name`, and `.embed(texts)` can be registered in
`get_embedder()` (384 dims drop in cleanly, e.g. MiniLM; for other
dimensions, `ALTER TABLE articles ALTER COLUMN embedding TYPE vector(N)`
then `python3 -m givemesomegoodnews.embed --all`).

## Running it

Postgres 16 with [pgvector](https://github.com/pgvector/pgvector), or use
the included compose file:

```sh
docker compose up -d
export DATABASE_URL=postgresql://givemesomegoodnews:givemesomegoodnews@localhost:5433/givemesomegoodnews

pip install -r requirements.txt
make all        # db + seed + about + feeds + build
make serve      # http://localhost:8000
```

`make refresh` (feeds + build) is the recurring job; it's idempotent —
articles dedupe on canonical URL. A crontab line like
`17 */3 * * * cd ~/givemesomegoodnews && make refresh` keeps the feed steady.
`DATABASE_URL` defaults to `postgresql:///givemesomegoodnews`.

Useful invocations:

```sh
python3 -m givemesomegoodnews.fetch_about --force            # refetch all about pages
python3 -m givemesomegoodnews.fetch_about hell-gate racket   # just these slugs
python3 -m givemesomegoodnews.fetch_feeds the-city           # crawl one org
python3 -m givemesomegoodnews.fetch_support --force          # re-find support links
python3 -m givemesomegoodnews.classify --dry-run             # tag report, no writes
python3 -m givemesomegoodnews.search "school board recall"   # vector search
```

## Adding a newsroom

Add an entry to `data/orgs.yaml` (slug, name, url; lat/lon for the map;
`about_url`/`feed_url`/`support_url` only if autodiscovery needs help),
then:

```sh
make seed && python3 -m givemesomegoodnews.fetch_about <slug> && python3 -m givemesomegoodnews.fetch_feeds <slug> && make build
```

## Provenance and politeness

- About text is copied from each org's About page deliberately — the point
  is their self-description, in their voice — always quoted, dated, and
  linked to the source. If any newsroom would rather not appear, delete
  its entry and reseed.
- The crawler fetches one About page and one feed per org per run, with a
  clear bot User-Agent. Feeds are the interface publishers offer for
  exactly this; headlines and summaries link to the original stories.
- Known gaps, current as of the first crawl: about text pending for a few
  sites behind bot walls (Gothamist meters bots via Tollbit; Verite,
  Mississippi Today, and Documented block non-browser TLS fingerprints —
  their feeds still work); no feeds found for the print-first Daily Sitka
  Sentinel and The News Reporter, for Invisible Institute and Wick
  Communications, or for The Beacon (its TLS is currently broken).

## Map

`givemesomegoodnews/albers.py` implements the standard Albers equal-area conic
for the lower 48 (parallels 29.5°/45.5°, central meridian 96°W) and
renders state outlines plus one dot per newsroom, clustered rings when
several share a city. Alaska/Hawaii and no-fixed-geography orgs are
listed below the map. State outlines derive from US Census data
(`data/us_states.geojson`).
