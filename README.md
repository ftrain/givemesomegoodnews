# Localpaper

**A catalog, coverage map, and combined feed of the local newsrooms being
built to last** — nonprofits, worker-owned cooperatives, family and
community papers, and metro dailies handed to civic institutions instead
of hedge funds. The Philadelphia Inquirer and the Lenfest Institute's
[Beyond Print](https://www.lenfestinstitute.org/institute-news/beyond-print-launches-11-newspaper-business-transformation-experiments/)
cohort, the [American Journalism Project](https://www.theajp.org/portfolio/)
portfolio, Hell Gate, Racket, Defector and its sister coops, the Baltimore
Banner, and the rest of the movement. They're surviving; this site is for
reading them.

The output is deliberately plain HTML — no CSS, no JavaScript. The one
image is an inline SVG map. Everything links back to the newsrooms.

## What's here

```
data/orgs.yaml          the catalog: 77 newsrooms (slug, url, place, model,
                        affiliations, feed hints). Add a newsroom here.
data/about_overrides/   hand-collected About text for sites whose firewalls
                        block scripted fetches (with source URLs)
data/catalog.json       machine-readable export, regenerated by the build
data/us_states.geojson  state outlines for the map (US Census-derived)
schema.sql              Postgres schema; requires pgvector
localpaper/             the pipeline (Python, four small dependencies)
site/                   the generated site (committed so it can be served
                        as-is, e.g. by GitHub Pages)
```

## How it works

1. **`seed`** upserts `data/orgs.yaml` into Postgres.
2. **`fetch_about`** pulls each org's About page and stores its main text —
   the catalog describes every newsroom *in its own words*, quoted and
   attributed, never paraphrased. Overrides in `data/about_overrides/`
   win over live fetches (for WAF-blocked sites).
3. **`fetch_feeds`** finds each org's RSS/Atom feed (configured hint →
   `<link rel="alternate">` autodiscovery → common paths, including the
   Arc and TownNews patterns), then stores new articles. Syndicated wire
   copy (`/wires/` URLs) is skipped. Every article gets an embedding at
   insert time.
4. **`build_site`** renders plain HTML from the database: the catalog
   grouped by state, an Albers-projected SVG coverage map, the combined
   feed newest-first, per-org pages, a self-contained `onepage.html`, and
   the cross-region **connections** page.

### The vector part

Articles live in an `articles` table with an `embedding vector(384)`
column and an HNSW cosine index (pgvector). That powers:

- **Connections across regions** — for recent articles, the nearest
  neighbor from a *different state*; the strongest pairs become
  `connections.html`. This is where you see five Western outlets carrying
  the same wildfire investigation, or Mississippi Today and Verite News
  circling the same police story from two states.
- **Related links in the feed** — cross-state echoes under feed items.
- **Search** — `python3 -m localpaper.search "housing eviction" -k 10`.

The default embedder (`localpaper/embedder.py`) is deterministic local
feature hashing: unigrams+bigrams hashed into 384 signed buckets, L2
normalized. No model downloads, no API keys, and good enough to catch
shared-vocabulary stories. It is built to be swapped: any embedder with
`.dim`, `.name`, and `.embed(texts)` can be registered in
`get_embedder()` (384 dims drop in cleanly, e.g. MiniLM; for other
dimensions, `ALTER TABLE articles ALTER COLUMN embedding TYPE vector(N)`
then `python3 -m localpaper.embed --all`).

## Running it

Postgres 16 with [pgvector](https://github.com/pgvector/pgvector), or use
the included compose file:

```sh
docker compose up -d
export DATABASE_URL=postgresql://localpaper:localpaper@localhost:5433/localpaper

pip install -r requirements.txt
make all        # db + seed + about + feeds + build
make serve      # http://localhost:8000
```

`make refresh` (feeds + build) is the recurring job; it's idempotent —
articles dedupe on canonical URL. A crontab line like
`17 */3 * * * cd ~/localpaper && make refresh` keeps the feed steady.
`DATABASE_URL` defaults to `postgresql:///localpaper`.

Useful invocations:

```sh
python3 -m localpaper.fetch_about --force            # refetch all about pages
python3 -m localpaper.fetch_about hell-gate racket   # just these slugs
python3 -m localpaper.fetch_feeds the-city           # crawl one org
python3 -m localpaper.search "school board recall"   # vector search
```

## Adding a newsroom

Add an entry to `data/orgs.yaml` (slug, name, url; lat/lon for the map;
`about_url`/`feed_url` only if autodiscovery needs help), then:

```sh
make seed && python3 -m localpaper.fetch_about <slug> && python3 -m localpaper.fetch_feeds <slug> && make build
```

## Provenance and politeness

- About text is copied from each org's About page deliberately — the point
  is their self-description, in their voice — always quoted, dated, and
  linked to the source. If any newsroom would rather not appear, delete
  its entry and reseed.
- The crawler fetches one About page and one feed per org per run, with a
  clear bot User-Agent. Feeds are the interface publishers offer for
  exactly this; headlines and summaries link to the original stories.
- Known gaps, current as of the first crawl: about text pending for a few
  sites behind bot walls (Gothamist meters bots via Tollbit; Verite,
  Mississippi Today, and Documented block non-browser TLS fingerprints —
  their feeds still work); no feeds found for the print-first Daily Sitka
  Sentinel and The News Reporter, for Invisible Institute and Wick
  Communications, or for The Beacon (its TLS is currently broken).

## Map

`localpaper/albers.py` implements the standard Albers equal-area conic
for the lower 48 (parallels 29.5°/45.5°, central meridian 96°W) and
renders state outlines plus one dot per newsroom, clustered rings when
several share a city. Alaska/Hawaii and no-fixed-geography orgs are
listed below the map. State outlines derive from US Census data
(`data/us_states.geojson`).
